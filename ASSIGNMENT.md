## Project: Local AI Experiment

Document your experience running and comparing a local AI model.

### Requirements
- Install and run **Ollama** or **LM Studio**
- Complete the **Three Prompts Exercise** (tool / collaborator / subject) with both a local model and a cloud model
- Create `experiment-notes.md` (see below)
- Include any **creative artifact** generated during the experiment

### experiment-notes.md (required)
Answer each in a few sentences:
1. Which local model did you run? Which cloud model did you compare to?
2. What felt different about using the local model?
3. Did the outputs differ? Give an example.
4. How did your relationship to the tool feel different — or did it?
5. What surprised you?

## Reflection

Write a **~300-word reflection** using the [reflection template](reflection-template.md).

**This week's critical prompt (Part 3):**

> *"What changes when you run an AI on your own computer vs. accessing one through a browser? Who controls the tool — and does that change how you use it or trust it?"*
